**Проект графического планшета**

-плата DE2-115 с FPGA Altera Cyclone IV E EP4CE115F29C7N

-мышь с интерфейсом PS/2

-LCD экран LT24 на базе контроллера ILI9341

**Папки:**

*src* - все исходники по модулям

*docs* - документы, тесткейсы, описание модулей

*tb* - тестбенчи для каждого модуля

*quartus* - проект для quartus 18.1 и все сопутствующие файлы

**Модули:**
1. lcd:

[lcd_top](src/lcd/lcd_top.vhd) - верхнеуровневый модуль для компановки всех модулей экрана

[cmd2lcd.vhd](src/lcd/cmd2lcd.vhd) - низкоуровневый интерфейс связи 8080 с экраном LT24  

[display.vhd](src/lcd/display.vhd) - высокоуровневый интерфейс экрана (реализация протокола, обновления экрана, передачи команд)

[rgb_test](src/lcd/rgb_test.vhd) - тестовый модуль для передачи конкретных параметров изображения

[timer](src/lcd/timer.vhd) - таймер на 33мс, использует PLL с 50Мгц на 100кГц

Пока что модуль display не ограничивает частоту обновления экрана таймером. Частота обновления зависит только от пропускной способности модулей display и cmd2lcd (~13мс на обновление всего экрана). Таймер на 33мс используется только для инициализации дисплея

**Тестбенчи:**
1. lcd:

[cmd2lcd_tb](tb/lcd/cmd2lcd_tb.vhd) - тестирование чисто модуля нижнеуровнего интерфейса cmd2lcd

[display_cmd2lcd_tb](tb/lcd/display_cmd2lcd_tb.vhd) - тестирование связки модуля disaplay и cmd2lcd. Таймер на 33мс можно подключить, а можно имитировать в самом тестбенче для ускорения симуляции.

*Тест 1* На вход подается только старт обновления экрана без данных. На выходе должны получить тестовые цветные полосы в нижней части экрана (этот тест заложен в display)

*Тест 2* На на вход подаются уже данные пикселей. На выходе должны получить экран красного цвета

*Тест 3* Тест обновления 5ти рандомных пикселей через single_upd_start. На выходе должны получить экран с измененными 5ю пикселями

[timer_tb](tb/lcd/timer_tb.vhd) - тестирование таймера на 33мс

[lcd_top_tb](tb/lcd/lcd_top_tb.vhd) - тестирование всего модуля lcd через rgb_test_simple
