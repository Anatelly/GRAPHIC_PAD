**Проект графического планшета**
-плата DE2-115 с FPGA Altera Cyclone IV E EP4CE115F29C7N
-мышь с интерфейсом PS/2
-LCD экран LT24 на базе контроллера ILI9341

Папки:
src - все исходники по модулям
docs - документы, тесткейсы, описание модулей
tb - тестбенчи для каждого модуля
quartus - проект для quartus 18.1 и все сопутствующие файлы

Модули:
1. lcd:
[lcd_top](src/lcd/lcd_top.vhd) - верхнеуровневый модуль для компановки всех модулей экрана
[cmd2lcd.vhd](src/lcd/cmd2lcd.vhd) - низкоуровневый интерфейс связи 8080 с экраном LT24  
[display.vhd](src/lcd/display.vhd) - высокоуровневый интерфейс экрана (реализация протокола, обновления экрана, передачи команд)
[rgb_test](src/lcd/rgb_test.vhd) - тестовый модуль для передачи конкретных параметров изображения
[timer](src/lcd/timer.vhd) - таймер на 33мс, использует PLL с 50Мгц на 100кГц
